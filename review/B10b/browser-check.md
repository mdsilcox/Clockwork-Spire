## Must-fix

1. **Overwind 7 salvage: Done silently does nothing when more than one part is kept.** Phone and desktop. The tray lets you mark all five parts "Keeping it", Done is enabled, and tapping it leaves the tray open with no message (the tray stays, Scrap unchanged). The core rejects it (`takeSalvage` returns false, `src/core/salvage.ts` line 45) and the UI ignores the false (`finish` in `src/ui/Nodes.tsx` ~line 268). Nothing tells the player about the "keep one" rule: the note still reads "Keep any of these parts for your bin." The twist is invisible in play. Fix: show the limit in the note ("Overwind 7: keep one"), disable further "Keep it" buttons or swap the choice once one is kept, and never let Done fail silently. Shots: `phone-salvage-ow7-allkept.png`, `phone-salvage-ow7-after-done.png`, `desktop-salvage-ow7-allkept.png`.
2. **Overwind 7 salvage preview shows the wrong Scrap.** Five unkept parts read "Scrapping the rest adds +15 Scrap" (3 each), but Overwind 7 pays 2 each (10). `SalvageScreen` calls `salvagePayout(p.items, keep, p.wrecked)` without `scrapPerScrapped(run, ...)` as the fifth argument (`src/ui/Nodes.tsx` ~line 267, `src/core/salvage.ts` line 49). The player is promised more than paid.
3. **Salvage note is missing its number.** Salvage tray, both sizes, any run: "What you leave is scrapped for Scrap." (reads `scrapped for {unit}` with no amount; `src/ui/Nodes.tsx` ~line 285). Should be "scrapped for 3 Scrap" (2 at Overwind 7). Likely existed before B10b, but the Overwind 7 rule makes the number matter.
