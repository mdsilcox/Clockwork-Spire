# Art trial (v1, 2026-10-04)

The owner's two approved samples that started the v2 graphics overhaul (DECISIONS.md D-026): Sprocket and the Foreman, generated with SDXL through the local toolkit (`~/.claude/tools/art/`) and rigged with `rig.js`. Open `sprocket/sprocket.html` or `foreman/foreman.html` in a browser; each is self-contained.

Kept here: the generation scripts, the picked cut-outs, the rig templates and the built pages. Not kept: the 8-seed candidates, recorded frames, clips and the video-model test (about 370 MB, left in the owner's untracked `art-trial/` folder).

This folder is reference only. v2 production art lives in `art/<asset>/` and follows `docs/art-direction.md` and `art/style.json`.
